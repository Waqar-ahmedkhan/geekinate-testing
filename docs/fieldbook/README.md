# The Living Fieldbook

## Reference and direction

The supplied RideMyPark frames show one map accumulating portraits, year captions and name stickers, followed by paper profiles, a dated archive and a contribution invitation. The live About page confirms the sequence from a personal list to a shared map. The 34.9-second timing and absence of audio come from the supplied recording analysis. No reference imagery is redistributed.

Geekinate's edition uses the studio's existing paper, ink and volt palette. An open notebook holds a continuous pencil route. The left leaf tells the story, the right leaf holds evidence. The ladder below the binding doubles as a chapter selector. Reading is manual until Play is selected.

## Assets

The paper, pencil path, map, building silhouettes and diagram are original procedural DOM/SVG artwork. The paper world uses CSS perspective to keep the existing shell's single WebGL canvas. Page-turn sound is synthesised with Web Audio. Typography inherits the site's local families. Project posters and clips are existing Geekinate case-study assets, used for their respective clients. Their inclusion here implies no independent redistribution license. Founder portrait, approved founder identity, interview and founding date are missing. A labeled sleeve reserves the portrait position. Project sequences illustrate the practice and imply no founding chronology.

## Running

Run npm install and npm run dev in the repository root. Open /meet-the-team2 on port 3008. The chapter manifest is in lib/content/notebook.js. Project data and routes come from lib/content/work.js. Build with npm run build. This edition follows the repository's Next.js and JavaScript conventions.
